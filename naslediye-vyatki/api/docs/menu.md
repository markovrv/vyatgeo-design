# Menu REST API

`GET nv/v1/menu/{location}`

Публичный эндпоинт для получения навигационного меню SPA. Реализован в теме
`wp-theme/naslediye-vyatki-theme/menu-api.php`.

## Регистрация меню

Тема регистрирует меню `spa_primary` (Главное меню SPA) через
`register_nav_menus` в `functions.php`. Редактор назначает меню в
**Внешний вид → Меню**.

## Параметры запроса

| Параметр | Тип | Описание |
|---|---|---|
| `location` | string | Slug локации меню (например `spa_primary`) |

## Формат ответа

Плоский массив пунктов меню:

```json
[
  {
    "id": 12,
    "title": "Новости",
    "url": "/news",
    "parentId": 0,
    "order": 3,
    "target": ""
  }
]
```

| Поле | Тип | Описание |
|---|---|---|
| `id` | int | ID пункта меню |
| `title` | string | Название пункта |
| `url` | string | URL как есть (после `wp_strip_all_tags`) |
| `parentId` | int | ID родительского пункта (0 — верхний уровень) |
| `order` | int | Порядковый номер |
| `target` | string | Атрибут target ссылки (например `_blank`) |

## Поведение

- Если локация не назначена ни одному меню — возвращается `[]` (пустой массив).
- Редакторы создают пункты как «Произвольные ссылки» в **Внешний вид → Меню**,
  вводя путь SPA-роутинга (`/news`, `/page/kontakty`, `/architecture`).
- `url` отдаётся как есть, без резолвинга `object_id`/`post_type` в SPA-путь.
- Вложенные пункты (`parentId > 0`) — фронтенд при необходимости строит дерево
  из плоского списка самостоятельно.
