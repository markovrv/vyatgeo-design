Вот полное описание проекта одним сообщением, готовое для использования в Claude:

***

**Проект: «Наследие Вятки»**

Просветительский веб-проект, посвящённый 90-летию образования Кировской области (5 декабря 1936 — 5 декабря 2026). Полное описание в заголовке страниц: «Наследие Вятки — Историко-культурное наследие Кировской области». Аудитория: жители области, туристы, краеведы, студенты. Концепция дизайна: «Дымковская игрушка встречает вятский северный модерн» — креативный ориентир системы называется «Берестяная летопись» (birch-bark chronicle): архивная, тактильная, рукотворная подача, где каждая страница читается как берестяная грамота с вписанной в неё историей края.

*Текущий статус: проект находится в стадии дизайн-прототипа — 17 статичных `.dc.html`-страниц на собственном dc-runtime (React-подобный шаблонизатор), без подключённого бэкенда. Контент представлен репрезентативными мок-данными; прототип служит эталоном дизайна до переноса на продакшн-стек.*

**Общая архитектура**

Проект задуман как лендинг-навигатор, объединяющий единым дизайном семь тематических разделов: шесть содержательных модулей наследия плюс раздел «О проекте». Продакшн-стек — React/Next.js (подтверждён для переноса); контент планируется подгружать из WordPress через REST-эндпоинты (custom post type на модуль), что разделит статичную презентационную оболочку (главная страница, навигация, брендинг) и динамический контент, пополняемый через админку WordPress без изменения фронтенда. На сегодня backend не подключён — это ещё не реализовано, а зафиксированное направление для следующего этапа.

Структура главной страницы (сверху вниз): sticky header с навигацией по всем разделам → hero-блок с параллаксом и CTA-кнопкой «Исследовать наследие» → сетка из 6 карточек-модулей (id="modules") → историческая справка (текст + вертикальный таймлайн XII в.—2026 г.) → блок народных промыслов (карусель из 3 карточек: дымковская игрушка, капокорень, кружевоплетение) → переходный блок «Архитектура» с параллаксом → блок с цитатой → footer с повторным перечнем разделов.

**Состав и структура шести содержательных модулей**

1. **Лица Победы** — каталог карточек (фото + описание), клик по карточке ведёт на страницу персоны с биографией, наградными листами и боевым путём. Хронологический охват — от XV века до новейшего времени.

2. **Исторические города Кировской области** — на главной странице модуля интерактивная карта (метки — 7 городов: Киров, Котельнич, Орлов, Слободской, Яранск, Малмыж, Уржум). Клик по метке ведёт на страницу города, где контент представлен как лента времени с карточками-записями, упорядоченными по годам, с фото и заголовком. Клик по карточке ленты ведёт на отдельную страницу события.

3. **Выдающиеся памятники археологии области** — интерактивная карта с метками (в попапе — фото и описание памятника, всего около 150 объектов). Клик по метке/попапу ведёт на страницу памятника с описанием ландшафта, историей исследований и данными о сохранности.

4. **Этнографическое наследие Кировской области** — каталог карточек (фото, название, краткое описание предмета/артефакта). Клик ведёт на страницу предмета с указанием места и времени бытования, этноса (русские, татары, удмурты, марийцы, коми).

5. **Архитектура города Кирова** — карта объектов (фото + название), клик по метке ведёт на страницу объекта с историческим и современным местоположением, стилем, декором, архивными изображениями (включая утраченные памятники и скульптуру).

6. **Памятники природы Кировской области** — свыше 100 охраняемых объектов с геопривязкой, описанием происхождения и режима посещения.

**Седьмой раздел: «О проекте»** — не каталог, а информационная страница: миссия проекта, блок статистики (7 разделов, ~150 памятников археологии, 100+ природных объектов, 5 этносов), перечень модулей-ссылок, научная база и партнёры (Правительство Кировской области, Кировский областной краеведческий музей, Вятский государственный университет, Кировское отделение Союза архитекторов России). Доступна из навигации, но не отображается карточкой в сетке модулей на главной.

**Карты объектов**

*Текущий прототип*: интерактивные карты трёх модулей (исторические города, памятники археологии, архитектура Кирова) реализованы как инлайновые SVG-карты с кликабельными метками — без внешнего картографического сервиса.

*Продакшн-план*: перенос на Яндекс.Карты API v3 как основной навигационный интерфейс для тех же трёх модулей:
- Метки кластеризуются при большом количестве объектов (актуально для ~150 памятников археологии).
- Попап метки содержит превью-карточку (фото + заголовок/краткое описание), клик по попапу или метке ведёт на страницу объекта.
- Карта синхронизирована с фильтрами: применение фильтра скрывает нерелевантные метки без перезагрузки страницы.
- Для модуля «Исторические города» карта — навигационный хаб верхнего уровня (7 меток), детальный контент раскрывается только на вложенной странице города в виде ленты времени.

**Единая система фильтров**

Один и тот же визуальный компонент фильтра используется во всех модулях — как над каталогом карточек, так и над картой. Набор параметров адаптируется к контенту модуля (период/война для «Лиц Победы», этнос для этнографии, эпоха для археологии, стиль для архитектуры), но визуальное поведение фильтра (расположение, анимация, состояния) остаётся идентичным везде. Результат фильтрации: в каталогах скрываются нерелевантные карточки, на картах — скрываются/подсвечиваются нерелевантные метки.

**Единая навигация между страницами**

- Хлебные крошки на детальных страницах (Главная → Модуль → Объект) для возврата на любой уровень.
- Кнопка «Назад к каталогу/карте» на всех детальных страницах.
- Общий header с навигацией по всем 7 разделам (6 модулей + «О проекте») доступен на любой странице сайта, включая внутренние страницы и карточки объектов.

**Дизайн-система**

Цвета: #FDFBF7/#FAF9F4 (топлёное молоко — фон), #3C7A8C (вятская бирюза — hover, метаданные), #C27E3A (ржаная охра — единственный акцент, используется на ≤10% площади экрана: кнопки, активные фильтры, точки таймлайна), #8B5E2B (тёмная охра — WCAG-safe вариант охры для мелкого текста/ссылок, где #C27E3A не проходит контраст 4.5:1), #E8DFC8 (белёный дуб — текст на тёмном), #2A2118 (чернильный — основной текст, футер, хедер), #F5F2EC (берёста — чередующиеся фоны секций), #5C5954 (глинистый — вторичный текст, метаданные), #D4C9AA (соломенный — пунктирные бордеры карточек и чипов), #FFFFFF (белый — фон карточек).

Шрифты: заголовки — Playfair Display, вес 700 (H1 52px/32px, H2 36px/26px, H3 22px/18px, desktop/mobile, через `clamp()`), текст — Roboto Slab (body 16px, line-height 1.75). Ровно два шрифта на весь проект, третий не допускается.

Отступы: шаг сетки 8px (8/16/24/40/64/96px), border-radius блоков 4px (чипы и теги — 999px, «пилюля»). Все карточки — border 1.5px dashed #D4C9AA («берестяная строчка»); охра на бордерах карточек не используется — только как редкий акцент. Кнопки — форма «фигурной скобы»: clip-path со срезом 8px по каждому углу, состояния default (охра) → hover (бирюза, подъём на 1px) → focus-visible (аутлайн). Формальный дымковский орнаментальный фон-паттерн с drift-анимацией в текущем прототипе не реализован — единственный орнаментальный элемент системы сейчас — декоративная SVG-волна с шестью точками в футере.

**Технические требования**

Mobile First (320px—2560px), breakpoints 767/1024px, кроссбраузерность Chrome/Firefox 100+/Safari 15+. Scroll-анимации через IntersectionObserver (fadeInUp, fadeInLeft), параллакс-эффекты в hero и архитектурном блоке, адаптивное мобильное меню (сайдбар справа), sticky header. Все анимации отключаются при prefers-reduced-motion: reduce, обязательны фокус-стили и alt-тексты для доступности, изображения — loading="lazy" с fallback-фоном при недоступности.
