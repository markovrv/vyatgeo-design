Анимации (IntersectionObserver)

fadeInUp — появление снизу (opacity + translateY).

fadeInLeft — появление слева.

Параллакс — hero-блок и архитектурный блок.

prefers-reduced-motion: reduce — все анимации отключаются.

/* Fade-in анимации через IntersectionObserver */
.anim-fade-up { opacity: 0; transform: translateY(30px); }
.anim-fade-up.visible {
opacity: 1; transform: translateY(0);
transition: opacity 400ms ease, transform 400ms cubic-bezier(0.16,1,0.3,1);
}
@media (prefers-reduced-motion: reduce) { *, *::before, *::after {
animation-duration: 0.01ms !important; transition-duration: 0.01ms !important;
}}

Навигация (SiteHeader + хлебные крошки)

SiteHeader — общий компонент со sticky-поведением и боковым мобильным меню.

Хлебные крошки — на всех детальных страницах: Главная → Модуль → Объект.
